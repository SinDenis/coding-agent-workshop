# Учебный трекер

`python tasks.py` показывает задачи. Команды одного запуска работают с общим списком
в памяти. Следующий запуск начинает с двух исходных задач. Сохранения на диск пока нет.

```sh
python tasks.py --command 'add Почитать' --command list
python tasks.py --command 'done 1' --command list
python -m unittest discover -v
```

Есть ошибка в завершении задачи: выполненной становится не та задача.
Исправьте реализацию, не меняя исходные тесты. Тесты должны стать зелёными.
При добавлении сохранения сначала согласуйте формат файла, его путь и ошибки чтения.
Не устанавливайте зависимости: проект использует стандартную библиотеку Python.
